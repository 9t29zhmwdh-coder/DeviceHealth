# Privacy Policy — DeviceHealth

## Summary

DeviceHealth processes all data locally. No data ever leaves your device.

## What We Collect

**Nothing.** DeviceHealth does not collect, store, transmit, or share any user data.

## Data Processing

- All processing is RAM-only unless explicitly exported by the user
- No data is transmitted to external services
- All AI analysis runs locally via Ollama at localhost:11434
- No telemetry, no analytics, no crash reporting

## Storage

- User settings stored in the OS application data directory
- No personal information in settings (configuration values only)
- No cloud sync of any kind

## Data Retention

Zero persistent session data. DeviceHealth retains no data between sessions beyond settings.
